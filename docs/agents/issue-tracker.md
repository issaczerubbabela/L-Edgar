# Issue Tracker

Issues for this repo live in [GitHub Issues](https://github.com/issaczerubbabela/L-Edgar/issues).

Agent skills (`to-tickets`, `to-spec`, etc.) use the GitHub CLI (`gh`) to read and write issues here.

**Workflow:**
- File an issue in GitHub Issues.
- Run `/to-tickets` (or similar) to turn it into a task.
- Agent skills will read from and write back to this tracker.
